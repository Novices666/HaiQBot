# `.dev/` —— 外部项目与第三方运行目录

这里放「跑起来才需要、且不属于本项目源码」的东西。**整目录不入库**（见 `.gitignore`）。

| 子目录 | 是什么 | 谁生成 |
|---|---|---|
| `napcat/` | NapCat 容器的宿主侧挂载：`config/`（含 WebUI / OneBot token，勿外传）、`qq/`（QQ 登录态）、`cache/`（扫码图等） | `scripts/init_napcat.py`、容器运行时 |

## 约定

1. **换机器时不要复制本目录** —— 里面是第三方凭据和登录态，复制过去等于搬运风险。
2. **新增外部工具统一放这里**（Lagrange、其它协议端、本地临时数据库等），不要再往仓库根堆。
3. `compose.yaml` 的挂载、`scripts/init_napcat.py` 的写入路径都指向 `.dev/`。
4. 本目录以点开头，`ls` 默认看不见 —— 这是有意的，别把它当成项目结构的一部分。

## 不在本约定范围内

`.pi/` 等 AI 工具目录、`.venv/` 依赖目录、`data/ logs/ secrets/` 运行时数据，
各有各的归属，保持原位。
